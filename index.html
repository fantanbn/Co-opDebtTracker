ยอดประจำกับยอดจ่ายเพิ่ม คำนวณอย่างไร?

คำนวณยอดประจำ 7,580 บาท ทุกวันที่ 25 โดยอัตโนมัติเมื่อถึงกำหนด ไม่ต้องกรอกซ้ำ เงินจ่ายเพิ่มที่ระบุจะรวมในวันที่ 25 ของเดือนนั้นเท่านั้น ไม่ใช้ซ้ำทุกเดือน

เดือนที่ไม่ระบุเงินเพิ่มถือเป็น 0 บาท การแก้เดือนเดิมจะแทนยอด ไม่บวกซ้ำ งวดล่วงหน้าไม่ถูกตัดจากยอดหนี้ปัจจุบัน และงวดสุดท้ายจะใช้ไม่เกินเงินต้นพร้อมดอกเบี้ยที่เหลือ

ตัวเลขเป็นประมาณการตามกำหนด ไม่ใช่ประวัติการรับชำระยืนยันจากสหกรณ์ หากวันหักจริงหรือวันโปะจริงต่างจากวันที่ 25 ต้องตรวจยอดกับสหกรณ์

ยอดทุกงวดในตารางเป็นประมาณการ วันที่ในอนาคตเป็นแผน ยังไม่หักจากยอดปัจจุบัน การล้างเงินเพิ่มไม่ยกเลิกยอดหักประจำ

สูตรและข้อจำกัดของยอดประมาณการ

ดอกเบี้ย = เงินต้นก่อนงวด × อัตราต่อปี ÷ 100 × จำนวนวันจริง ÷ 365 ค่าเริ่มต้นปัดเป็นบาทเต็ม ซึ่งตรงกับข้อมูลใบเสร็จ 4 งวดที่ตรวจสอบ

ยอดเริ่มต้น 377,878 บาท เป็นยอดหลังชำระ 25 ก.ย. 2569 งวดแรกที่คำนวณต่อคือ 25 ต.ค. 2569 ยอดประจำ 7,580 บาทไม่รวมค่าหุ้นและประกัน เงินเพิ่มถือว่าจ่ายพร้อมยอดประจำในวันที่ 25

เมื่อเปิดเว็บ ระบบคำนวณงวดที่ถึงวันที่ 25 แล้วตามวันที่ในอุปกรณ์ ไม่ต้องเปิดเว็บทุกเดือน และไม่บันทึกรายการประจำซ้ำลงข้อมูล เวลาผ่านไปยอดประมาณการจึงเปลี่ยนได้โดยไม่ได้รับข้อมูลจากสหกรณ์

ไม่รองรับงวดที่หยุดจ่าย อัตราเปลี่ยนกลางสัญญา หรือวันหักที่ไม่ใช่วันที่ 25 ยอดจริงต้องยืนยันกับสหกรณ์ ไม่ใช่ยอดปิดบัญชีรับรอง

ตั้งค่า Cloud / Make.com (ไม่บังคับ)

โหมดรายเดือนปิด Cloud เป็นค่าเริ่มต้น ไม่ใช้ Webhook เดิมอัตโนมัติ ควรเปลี่ยน URL เดิมที่เคยเปิดเผยใน GitHub ก่อนใช้

ส่งเฉพาะเมื่อคุณบันทึกเงินเพิ่มเดือนใหม่ ไม่ส่งอัตโนมัติเมื่อเปิดเว็บหรือเมื่อถึงกำหนด ยอดที่ส่งเป็น monthly_estimate ไม่ใช่รายการจ่ายจริง โปรดปรับ Make.com ให้รองรับข้อมูลเวอร์ชันนี้ก่อนเปิด

ใช้ record_id รูปแบบ monthly-YYYY-MM ป้องกันรายการซ้ำ การแก้เดือนเดิม ล้างเงินเพิ่ม หรือเปลี่ยนข้อมูลที่กระทบเดือนที่ส่งแล้ว จะไม่แก้ Sheet อัตโนมัติ ต้องปรับ Sheet เอง HTTP สำเร็จเพียงยืนยันว่า Make.com รับคำขอแล้ว
