ดอกเบี้ยประมาณการ = เงินต้นคงเหลือ × อัตราต่อปี ÷ 100 × จำนวนวันจริง ÷ 365 ค่าเริ่มต้นปัดดอกเบี้ยเป็นบาทเต็มตามข้อมูล 4 งวด มิ.ย.–ก.ย. 2569 ที่ตรวจสอบ สามารถเลือกปัดสองตำแหน่งได้ในตั้งค่า

ใช้วันที่รับชำระเป็นจุดเริ่มช่วงคำนวณถัดไป กรณีเลือก “โปะเงินต้นล้วน” ดอกเบี้ยช่วงก่อนโปะจะถูกสะสมแบบไม่ปัดเศษไปคิดในงวดปกติถัดไป โดยไม่ทบเป็นเงินต้น รายการวันเดียวกันมีช่วงวันเป็น 0 โดยเรียงตามลำดับบันทึก หากกรอกดอกเบี้ยตามใบเสร็จ จะใช้ยอดนั้นแทนสูตร ไม่รองรับการชำระต่ำกว่าดอกเบี้ยที่คำนวณ/ระบุ และยังไม่จำลองการพักชำระ ดอกเบี้ยค้าง หรือการเปลี่ยนอัตราระหว่างงวด

การโปะอาจมีวิธีจัดสรรดอกเบี้ยต่างจากงวดปกติ ควรใช้ใบเสร็จจริงเป็นหลัก ฐาน 365 วันรวมถึงกติกาปีอธิกสุรทินและการปัดเศษยังควรยืนยันกับสหกรณ์ ตัวเลขจำลองไม่ใช่ยอดปิดบัญชีอย่างเป็นทางการ

ข้อมูลหน้าเว็บเก็บเฉพาะเบราว์เซอร์/เว็บไซต์นี้ ไม่ได้ดึงจาก Google Sheets อัตโนมัติ ควรสำรอง JSON เป็นประจำ โดยเฉพาะก่อนเปลี่ยนเครื่องหรือล้างข้อมูลเว็บไซต์

ตั้งค่า Cloud / Make.com (ไม่บังคับ)

Webhook เดิมเคยปรากฏใน Repository สาธารณะ ควรเพิกถอน/เปลี่ยน URL ที่ Make.com ก่อนใช้อีกครั้ง ไฟล์นี้ไม่ฝัง URL เดิมและปิด Cloud เป็นค่าเริ่มต้น

การบันทึก URL ยังไม่ส่งข้อมูล แต่รายการชำระใหม่จะส่งวันที่ ยอดชำระ ดอกเบี้ย เงินต้น ยอดคงเหลือ หมายเหตุ และ ID ไปยัง Make.com ที่ระบุ “รับคำขอแล้ว” หมายถึง HTTP สำเร็จ ไม่ได้ยืนยันว่าเขียนลง Sheet แล้ว ไม่มีการลองส่งซ้ำอัตโนมัติ

เพิ่มย้อนหลัง ลบรายการ เปลี่ยนจุดตั้งต้น หรือนำเข้าข้อมูล: จะไม่เขียนทับ Sheet อัตโนมัติ ต้องตรวจปรับข้อมูลใน Sheet ให้ตรงกัน แนะนำให้ workflow ใช้ record_id ป้องกันรายการซ้ำ

จำลองโดยใช้วันชำระจริงในแต่ละเดือน ฐาน 365 วัน สมมติอัตราคงที่และไม่มีรายการอื่นระหว่างงวด
